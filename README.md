# 水星计划 · 交互原型 v0.1

**启动方式：双击「水星计划」快捷方式**（在桌面和这个文件夹里各有一份），窗口建议不小于 1280×800，不需要安装任何东西。

快捷方式用的是 Edge 的独立配置，所以每次都会单独开一个「水星计划」窗口，不受你平时浏览器的标签页影响。如果哪天快捷方式失效，双击 `启动水星计划.cmd` 效果一样。

> 注意：这个文件夹的路径不要挪动，快捷方式记录的是绝对路径。

## 这一版能做什么

- **今日总览**：三栏工作台。左侧日程 + 当日琐事，中间今日焦点 + 习惯打卡，右侧戒除连续天数 + 那年今日。所有卡片都能就地操作，不用跳页。
- **日程待办**：日视图（时间轴）和清单两种看法；顶部一行自然语言添加；勾选完成可撤销；逾期集中提示、一键顺延；一键清理已完成的待办。
- **目标拆解**：左树右详情，最多五层；进度由子项自动汇总；任何行动都能「排进今天」变成待办；删目标会连子项一起删。
- **我的项目**：卡片墙 + 右侧详情抽屉；每张卡都突出一个「下一步」；可把下一步直接排进今天。
- **习惯**：养成 / 戒除两个页签。养成习惯有 7 日格子（可补卡）；戒除习惯只记连续天数，破戒后归零但保留最长纪录与累计天数。
- **心愿清单**：卡片墙，按想要程度排序，「标记已实现」会自动生成一条成就。
- **琐事记录**：月历回看 + 按天分组的时间流，点日历任意一天定位到那天。
- **成就**：时间轴 + 今年/累计/最近统计；项目完成、目标达成、心愿实现、习惯里程碑都会自动进来。

## 删除与找回

每个模块都能删，而且删错了都能捡回来：

- **删除入口在鼠标经过时出现**：把鼠标移到任意一条待办、琐事、目标、习惯、项目、心愿、成就上，右侧（卡片右上角）会出现一个垃圾桶图标。触屏设备上图标会一直显示。
- **行内项**（待办、琐事）点了就先删，底部弹出「已删除 … 撤销」，5 秒内点一下就能还原，位置也回到原处。
- **整块内容**（目标、项目、习惯、心愿、成就）会先弹窗确认，避免误删。删目标会连同它的所有子项一起删；由它排出来的待办会保留，只是不再关联。
- **回收站**：设置 → 回收站，能看到最近删除的 40 条记录，逐条「恢复」。恢复时会挂回原来的位置（比如删掉的子目标会回到它原来的父目标下面）。
- **快捷键**：焦点在某条删除按钮上时按 `Delete` 或 `Backspace` 触发删除；`Ctrl Z` 撤销刚才那一步删除（在输入框里打字时不受影响）。
- **清理已完成**：日程待办页右上角，可以把所有已完成的待办一次性清掉，同样支持撤销。
- **重置演示数据**也加了二次确认，不会再点一下就清空。

## 可以试的几件事

1. 在今日总览的「添加任务」里输入：`明天 15:00 交周报 !高 @水星计划`
2. 勾掉一条待办，5 秒内点「撤销」
3. 习惯页点 7 日格子补卡；「喝水 8 杯」点一下 +1，右键 −1
4. 点「我破戒了」，看连续天数归零、最长纪录保留
5. 目标页点「排进今天」，再回日程待办看
6. 琐事页点日历里的任意一天，右边会定位到那天
7. 按 Ctrl K，输入「习惯」试试命令面板
8. 把鼠标移到一条待办上，点右边冒出来的垃圾桶，再点「撤销」；然后去 设置 → 回收站 看看

## 快捷键

| 键 | 作用 |
| --- | --- |
| Ctrl K | 搜索 / 跳转 |
| Ctrl Shift Space | 快速记录（任务 / 琐事 / 成就） |
| Ctrl Z | 撤销刚才的删除 |
| Delete / Backspace | 删除当前聚焦的那一条（焦点在删除按钮上时） |
| Esc | 关闭弹层、抽屉 |

## 数据说明

这是用来确认交互的原型，数据只保存在本机，设置里可以「重置演示数据」。正式版会换成真正的本地数据库，并加上自动备份和导出。

删掉的东西不会立刻消失：它们会先留在「设置 → 回收站」里，最多 40 条，随时可以恢复；超过 40 条时最早的那条才会被挤掉。
