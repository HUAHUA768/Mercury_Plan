# 2026-10-31

## 新增「日常记录」模块（周期重复事项）

需求：新开模块记录周期重复的事（如洗浴巾），可反复追加「哪天做的（必填）+ 预计下次（可选）」。

改动文件：`ui/app.js`（+448）、`ui/styles.css`（+74）、`README.md`（+3）。Rust 端未动。

### 数据模型
```js
routines: [{
  id, name, icon, cycleDays: number|null, note,
  logs: [{ id, date, next: 'YYYY-MM-DD'|null, note }]
}]
```
- `next` 优先级：上一条记录里填的 `next` > 按 `cycleDays` 从上次日期推算 > 无安排（state: 'none'）
- 到期状态 state：`over`(逾期) / `today` / `soon`(≤7天) / `later` / `none`，列表按此排序

### 关键实现位置（都在 app.js 的 IIFE 内）
- 派生函数：`routineLogs / routineLast / routineNext / routineAvgGap / routineDue / routineSorted / routinesDue`
- 页面：`viewRoutines()` + `routineRow()` + `nextBadge()`；分页 seg：全部 / 该做了
- 抽屉：`drawerRoutine(id)`（累计次数、平均间隔、全部记录、删记录）
- 弹窗：`openNewRoutine()`（名称/周期/备注）、`openRoutineLog(id)`（日期必填 + 下次可选 + +7/14/30/按周期/清空 快捷按钮）
- 删除：`delRoutine`（进回收站、可撤销）；`delRoutineLog`（单条记录走 toast 撤销，不进回收站）
- 入口：侧栏「记录」组第一项（图标 `cycle`）、今日总览「日常该做了」卡片、命令面板「新建日常事项」

### 兼容性处理（重要）
- 旧 localStorage 数据：`if (!Array.isArray(S.routines)) S.routines = []`，并补 `ui.routineTab`
- 旧备份导入：`validateBackup` 之前先补 `payload.data.routines = []`，否则会被校验拦下
- `BACKUP_ARRAYS` 已加入 `'routines'`

### 构建陷阱（重要，下次别再踩）
`src-tauri/tauri.conf.json` 只有 `frontendDist: "../ui"`，**没有 `devUrl`**：前端三个文件在编译期被 tauri-codegen 压缩嵌入 exe。因此：
- 改完 `ui/` 必须重新编译，否则双击 exe 看到的还是旧版；连 `npm run dev` 也没有热更新，要重启才生效
- 桌面快捷方式 `%USERPROFILE%\Desktop\水星计划.lnk` → `E:\Mercury_Plan\src-tauri\target\release\mercury-plan.exe`
- 重建命令：`npx tauri build --no-bundle`（只出 exe，约 1.5 分钟）；`npx tauri build`（带 NSIS 安装包）；
  debug 版用 `cd src-tauri && cargo build`（让 `npm run dev` / 双击 debug exe 也是新版）
- 验证办法：资源以 **brotli 压缩块** 内嵌，直接 grep exe 无效（旧关键字也搜不到）。
  正确做法是读 `target/<profile>/build/mercury-plan-*/out/tauri-codegen-assets/<sha>.<ext>`，
  用 `zlib.brotliDecompressSync` 解压后与 `ui/` 源码逐字节比对，再确认该压缩块字节存在于 exe 中。
  注意该目录会累积历史残留哈希文件（不同 profile 的压缩参数不同，哈希也不同）。

### 验证方式
无 Rust 改动，用 vm + 最小 DOM 桩跑 app.js 做冒烟（脚本在系统 Temp：`mercury-smoke.js` / `mercury-migrate.js`），36 项断言全通过，覆盖渲染、排序、分页、抽屉、弹窗、快捷日期、保存/更新、删除+回收站恢复、旧数据迁移。
注意写同类桩测试时：`setTimeout` 要能真正执行（confirm-ok 走 setTimeout），且 stub 元素的 `remove()` 必须真的从父节点移除，否则 toast 里的 `while (wrap.children.length > 3)` 会死循环。
